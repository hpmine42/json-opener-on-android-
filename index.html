JSON Opener

        
Öffnet JSON-Dateien direkt aus dem Android-Teilen-Menü – ohne die Datei in eine App zu importieren.


        
Installieren

        
    
          
  1. Öffne diese Seite im Chrome auf deinem Google Pixel.
    2. 
          
  2. Tippe auf ⋮ → „App installieren“ (oder „Zum Startbildschirm hinzufügen“).
    3. 
          
  3. Die App erscheint mit dem { }-Icon auf dem Startbildschirm.
    4. 
        


        
JSON-Datei öffnen

        
    
          
  1. Tippe in der geteilten Datei auf „Teilen“.
    2. 
          
  2. Wähle im Teilen-Menü JSON Opener.
    3. 
          
  3. Die Datei wird sofort geöffnet und angezeigt.
    4. 
        


        
In der App

        
    
          
  • ✓ Baumansicht – Objekte & Arrays auf- und zuklappen
    • 
          
  • ✓ Suche – Schlüssel & Werte durchsuchen (⌘F / Strg+F)
    • 
          
  • ✓ Rohdaten – formatiert oder kompakt ansehen
    • 
          
  • ✓ Weiterteilen – Datei als .json an andere Apps schicken
    • 
          
  • ✓ Speichern – als .json-Datei herunterladen
    • 
          
  • ✓ Copy – Inhalt als Text kopieren
    • 
          
  • ✓ Schema – Struktur-Übersicht mit Pfaden & Typen
    • 
          
  • ✓ Offline – funktioniert ohne Internetverbindung
    • 
        


        
Hinweise

        
Alle Daten bleiben auf deinem Gerät. Es werden keine Dateien hochgeladen.

        Große Dateien (mehrere MB) werden in der Baumansicht verzögert aufgebaut, damit alles flüssig bleibt.
